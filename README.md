# 🏗️ Baustellen-Tracker

Eine einfache, lokale Web-App zum Tracken deines Baustellenfortschritts — direkt über GitHub Pages.

## Features
- **Übersicht**: Aufgaben mit Status, Zeitleiste, Budget, Hinweis, Link und Datei. Unteraufgaben möglich.
- **Kalender**: Zeitstrahl (Gantt) aller Aufgaben mit eingetragenen Daten.
- **Aktuell**: Separate To-Do-Liste mit Fälligkeitsdatum und Überfälligkeits-Warnung.

## Daten
Alle Daten werden lokal im `localStorage` des Browsers gespeichert — kein Server nötig.
